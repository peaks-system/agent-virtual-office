# AI Corporation dashboard design

Approved direction: user screenshot and explicit selection of all four features, 2026-09-08.

Desktop: white shell with 88px header, 270px left rail, flexible central white office (800:560), 330px right rail. Header contains green monogram, AI CORPORATION, Japanese subtitle, restrained status cards and time. Thin gray borders, rounded 18px panels, ivory canvas, dark slate body text, emerald accent. No screenshot assets or copied room plan.

Left: project heading/add action, selectable project cards with derived checklist progress and manual-data label, staff list below with original block avatars, role and honest external status. Center: four-room office with its existing controls and activity history, enough space for complete view. Right: selected-project title/description, editable plan and task checklist, real work statuses with connection provenance. Empty state provides a clear add-project action. Forms use labels, visible focus and explicit save feedback. Export provides local JSON backup.

At widths below 1100px rails wrap into a vertical layout rather than crop the office. At mobile width header counters wrap, office remains complete, panels follow in reading order. Panel embed mode retains the existing office-only UI. Japanese control text except requested AI CORPORATION and STAFF LIST signs.

No fake progress: task percentage reflects user-controlled completed checklist items. Real AI work shows only received status payloads; unconnected state is explicit.
